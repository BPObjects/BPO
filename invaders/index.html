Ce n'est pas une émulation. Reconstruction d'après le manuel de la cartouche PHM 3053 et les descriptions publiques du jeu : aucun octet d'origine. Les onze créatures, leurs quatre images d'animation et leurs couleurs sont relevées sur la vidéo de Jason Doucette (« All 11 invaders »), où il les tape en Extended BASIC d'après le code source : le jeu les faisait glisser de deux points en deux points, chaque image portant la forme un peu plus à droite — c'est repris tel quel. Police d'Extended BASIC relevée sur la même vidéo, quinze couleurs du TMS9918A, son par un SN76489 reconstitué.

Les règles du manuel. Onze créatures de front sur cinq rangs, les moins chères en tête, les plus chères à l'arrière ; la horde accélère à chaque perte. Deux humeurs : merely aggressive — elles tirent vite mais sans vous voir — et downright nasty — elles vous visent, et valent le double. Trois missiles, un de plus au-delà de 3 000 points, un missile démoli réparé tous les 10 000. Le vaisseau de contrôle jaune passe toutes les vingt secondes environ : de 25 à 300 points selon l'endroit touché. Quand le rang est vide, le vaisseau rouge traverse l'écran : chaque coup le rétrécit, le fait faire demi-tour et retarde l'attaque suivante. Puis viennent les espèces que les auteurs avaient baptisées dans leur code : SNAKE, TURNOVER, HALF FLASHER WITH EYES, PULSAR, BAT, 11000 FLASHER, 00111 FLASHER — et les EYES.
