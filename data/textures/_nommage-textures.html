Textures photo — comment nommer tes fichiers

Dépose tes images seamless (qui se raccordent), carrées de préférence, dans data/textures/. Nomme chaque fichier avec l’id exact ci-dessous, en .jpg. Exemple : pour « Parquet chêne naturel », le fichier doit s’appeler parquet_chene.jpg. Chaque photo remplace automatiquement la version dessinée ; les fichiers absents gardent le rendu procédural. Format accepté : jpg (ou png/webp via le manifest). 512×512 ou 1024×1024 idéal.
